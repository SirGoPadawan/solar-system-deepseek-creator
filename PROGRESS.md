## Что это

Демо-сцена на Three.js (r186): Солнечная система с процедурными текстурами планет,
фоновой туманностью, звёздным полем и дрейфом всей системы по спирали в космосе.

## Файлы проекта

- `index.html` — точка входа, importmap указывает на **`vendor/three/`** (не на `node_modules`).
- `index.js` — вся сцена. **Основной файл, который мы дорабатываем.**
- `server.js` — статический сервер без зависимостей (для `npm start`), ESM.
- `vendor/three/` — закоммиченный three.js (`three.module.js`, `three.core.js`) + `addons/controls/OrbitControls.js`.
- `.nojekyll` — пустой файл, отключает Jekyll на GitHub Pages.
- `README.md` — инструкция по запуску/деплою + упоминание модели.
- `index.js.bak` — резервная копия исходной версии (до всех правок).
- `node_modules/` — локальные зависимости (в `.gitignore`, для разработки).
- `PROGRESS.md` — этот файл.
- `solar.jpg`, `2.png` — референсы внешнего вида.

## Как запускать

Одной командой:

```bash
npm start
```

Открыть: http://localhost:8000 (обновлять через Ctrl+F5, чтобы сбросить кэш).
Другой порт: `PORT=3000 npm start`. Остановить — Ctrl+C.

Проверено: `npm start` поднимает `server.js`, отдаёт `index.html`, `index.js`,
`three.module.js` с корректным `Content-Type: text/javascript` (иначе ES-модули не грузятся).

## Что уже сделано

### Этап 1. Багфиксы и структура (первый проход)
- Меркурий и Венера раньше были **чёрными** (в генераторе не было веток для этих типов) — добавлены текстуры.
- Освещение дальних планет: у `sunLight` теперь `decay = 1` (мягкое затухание вместо квадратичного) —
  Юпитер и Сатурн больше не чёрные.
- Анимация переведена на `THREE.Clock` + `delta` — скорость не зависит от FPS.
- Планеты вынесены в массив `PLANETS` (было — позиционные аргументы).
- Тень: `SHADOW_MAP_SIZE` снижен 2048 → 1024.
- Мелкие планеты используют 32 сегмента сферы вместо 64.
- Линия орбиты теперь в той же группе, что и планета (плоскости совпадают).
- Ограничения камеры (`minDistance/maxDistance/maxPolarAngle`), `pixelRatio` при ресайзе.
- Обработка отсутствия WebGL (`try/catch` + сообщение).
- Оставлен бэкап `index.js.bak`.

### Этап 2. Полностью новые процедурные текстуры
Раньше были плоские кружки и жёсткие полосы («нулевые»). Заменено на шум:
- value-noise + fBm, сглаживание, палитры-градиенты, расчёт **по каждому пикселю** через `ImageData`.
- **Бесшовность по горизонтали** (координаты заворачиваются по модулю периода) — нет шва на сфере.
- Индивидуальная текстура на каждую планету:
  - Солнце — грануляция фотосферы;
  - Меркурий — серый, кратеры/бассейны;
  - Венера — горизонтальные вихри облаков;
  - Земля — океан/суша по порогу высоты, лёд на полюсах, отдельный слой облаков (океан ~2/3);
  - Марс — ржавые равнины + небольшие полярные шапки;
  - Юпитер — контрастные пояса + зональные потоки + **Большое Красное Пятно** (оверлей);
  - Сатурн — мягкие кремово-золотые пояса.
- **Разрешение текстуры зависит от размера планеты**: `textureSize(radius)` →
  1024 (Солнце) / 768 (гиганты) / 512 (мелкие). Экономит время генерации (~1.1 c вместо ~2.2 c).
- Кэш текстур по ключу `тип@размер`.
- Звёзды: разброс по сферической оболочке, цветовой разброс, аддитивное смешивание, `depthWrite:false`.

### Этап 3. Туманность и дрейф по спирали
- Корневая группа `world` — содержит всю систему (планеты, орбиты, свет `sunLight`/`rimLight`, ореол).
- **Туманность**: сфера радиусом 600 (`BackSide`, `toneMapped:false`, `depthWrite:false`);
  текстура из «гребневого» fBm + низкочастотный выбор оттенка (бирюза → фиолет → маджента).
- **Дрейф по спирали** в `animate()`: `world` движется по винтовой траектории (`x/z` — виток,
  `y` — покачивание) + лёгкий наклон `rotation.x/z`.
- Звёздное поле и туманность плывут навстречу (параллакс → ощущение полёта).

### Этап 4. Текущий проход
- **Исправлен «квадрат» вокруг Солнца**: у `sunGlow` (Sprite) не был выставлен `transparent: true`,
  из-за чего квад рендерился с видимыми границами. Добавлено `transparent: true, depthWrite: false`.
- Создан этот файл `PROGRESS.md`.

### Этап 5. Полёт сквозь космос + винтовые следы (по референсу solar.jpg)
Референс `solar.jpg` в корне проекта: система летит вперёд, планеты оставляют спиральные следы,
камера-наблюдатель стоит на месте.

- **Убрано прежнее круговое движение `world`** (спираль теперь передаётся следами, а не дрейфом группы).
- **Камера статична** — движение системы наблюдатель видит за счёт фона.
- **Бесконечное звёздное небо**: звёзды разложены равномерно в кубе `STAR_BOX` и каждый кадр
  сдвигаются против `MOTION_DIR` с оборачиванием координат в кубе (`wrapBox`) → небо стримится
  навстречу бесконечно, без «улетания» системы из кадра.
- **Винтовые следы** для Солнца и всех планет (`updateTrails`): след строится **аналитически** —
  берётся орбита тела за прошедшее время `TRAIL_TIME` и точки смещаются назад на `MOTION_SPEED*age`.
  Итог: орбита + полёт = спираль (винт). Солнце (distance 0) даёт прямую золотую нить.
  Цвет затухает к хвосту (`vertexColors` + `AdditiveBlending`).
- Параметры полёта: `MOTION_DIR`, `MOTION_SPEED`; следы: `TRAIL_TIME`, `TRAIL_POINTS`, `trailColors`.

### Этап 6. Наклон системы и ускорение
- **Наклон всей системы**: `world.rotation.set(SYSTEM_TILT_X, 0, SYSTEM_TILT_Z)` — плоскость орбит
  встала под углом к направлению полёта (больше не «летит на тарелке»).
- Важно: наклон применяется **и к следам** (`trailVec.applyEuler(systemTilt)`), иначе следы разъедутся
  с планетами (они считаются аналитически в локальных координатах).
- Скорость полёта: `MOTION_SPEED` 4 → 5.5.

### Этап 7. Правильный наклон: спирали ⟂ система
- Проблема была в том, что направление полёта **не совпадало с нормалью плоскости орбит**, поэтому
  спирали уходили «вбок», а плоскость выглядела плоской («тарелка»).
- Теперь `MOTION_DIR` **вычисляется как нормаль плоскости орбит после наклона**:
  `(0,1,0).applyEuler(SystemTilt)`. Значит следы всегда идут перпендикулярно системе.
- Наклон изменён на `SYSTEM_TILT_X = 0.15`, `SYSTEM_TILT_Z = 0.6` — плоскость читается как
  наклонённый диск (эллипсы), проверено: сжатие орбит ≈ 0.49 при данной камере.
- Важно: если менять `SYSTEM_TILT_*`, `MOTION_DIR` пересчитывается автоматически (он производный).

## Известные особенности / что можно доработать

- Движение системы — **иллюзия**: `world` стоит в центре, стримятся звёзды и рисуются следы.
  Так камера-наблюдатель не двигается, а система не улетает из кадра.
- `MOTION_DIR` должен совпадать для звёзд и следов (одно направление) — иначе разъедется.
- Следы строятся аналитически и предполагают, что группа `world` в начале координат.
  Если снова начнёшь двигать `world`, следы нужно пересчитывать с учётом его матрицы.
- Скорость/выдержка следов настраиваются `MOTION_SPEED`, `TRAIL_TIME` (больше = длиннее спираль).
- Туманность (`nebula`) статична (сфера-скайбокс нельзя двигать — станут видны края).
- Стоимость генерации текстур на старте ~1.1 c (синхронно). Можно сделать ленивую/прогрессивную генерацию.
- Кольца Сатурна — простая полупрозрачная заготовка, можно улучшить (текстура-щели, тени).
