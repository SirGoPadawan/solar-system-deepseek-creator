# 🌌 Three.js — Солнечная система

Интерактивная 3D-сцена Солнечной системы на [Three.js](https://threejs.org/):
процедурные текстуры планет, фоновая туманность, бесконечное звёздное небо и полёт
системы сквозь космос с винтовыми (спиральными) следами планет.

## ✨ Что есть в сцене

- Солнце + **8 планет**, включая Уран и Нептун.
- **Процедурные текстуры** (шум fBm) и наклоны осей планет (`axialTilt`).
- **Атмосферное свечение** (fresnel) у Земли, Венеры, Марса и газовых гигантов.
- **Кольца Сатурна** из нескольких полос со щелями.
- **Спутники планет**: Луна, Фобос/Деймос, галилеевы спутники, Титан, Тритон и др.
- **Искусственные аппараты**: МКС, Hubble, Juno, Cassini, Voyager 2, Akatsuki — с мигающими маяками.
- **Пояс астероидов** (между Марсом и Юпитером) и **пояс Койпера** (за Нептуном).
- Фоновая туманность + стримящееся звёздное небо и **винтовые следы** (иллюзия полёта).

## 🚀 Быстрый запуск (одной командой)

```bash
npm start
```

Затем открой в браузере:

**http://localhost:8000**

Остановить сервер — `Ctrl+C`.

> Ничего доустанавливать не нужно: `npm start` запускает встроенный статический
> сервер (`server.js`) без внешних зависимостей.

### Другой порт

```bash
PORT=3000 npm start
```

### Почему не открыть `index.html` напрямую?

Проект использует ES-модули (`import` + `importmap`). Браузеры не грузят модули по
протоколу `file://`, поэтому нужен http-сервер — `npm start` его и поднимает.

## 🎮 Управление

- **ЛКМ + перетаскивание** — вращение камеры вокруг системы.
- **Колесо мыши** — приближение/отдаление.
- **ПКМ + перетаскивание** — сдвиг.

Камера-наблюдатель статична: ощущение полёта создаётся движущимся звёздным небом и следами планет.

## ⚙️ Что можно настроить

Все ключевые параметры — в начале `index.js`:

```js
const PLANETS = [ ... ]        // состав системы: радиус, орбита, скорости
const MOTION_SPEED = 5.5       // скорость «полёта» сквозь космос
const SYSTEM_TILT_X = 0.15     // наклон плоскости системы
const SYSTEM_TILT_Z = 0.6
const TRAIL_TIME = 16          // длина спиральных следов
```

- `MOTION_DIR` **производный** — это нормаль плоскости орбит, поэтому спирали всегда
  перпендикулярны системе. Меняя `SYSTEM_TILT_*`, вы разворачиваете систему, и полёт
  подстраивается сам.
- Спутники и аппараты задаются прямо в планете: `moons: [{ name, radius, distance, orbitSpeed, color }]`
  и `artificial: [{ name, distance, orbitSpeed, inclination }]`.
- Пояса малых тел: `makeBelt(...)` — `asteroidBelt` и `kuiperBelt`
  (`count`, `inner`/`outer`, `speedMin`/`speedMax`, `scaleMin`/`scaleMax`).
- Текстуры планет генерируются процедурно (шум fBm) — палитры `SUN`, `LAND`, `JUPITER_BANDS`
  и т.п. тоже в `index.js`.

Подробнее обо всех этапах — в `PROGRESS.md`.

## 🌐 Публикация на GitHub Pages

Проект — чистая статика, поэтому публикуется «как есть». Важно: `node_modules`
в `.gitignore` **не** коммитится, поэтому three.js закоммичен отдельно в `vendor/`,
а `index.html` через `importmap` ссылается именно на `vendor/`. Значит на GitHub Pages
всё заведётся без сборки.

### Первичная настройка (один раз)

1. Запушьте ветку `main`:
   ```bash
   git add .
   git commit -m "Add moons, belts and GitHub Pages setup"
   git push origin main
   ```
2. В репозитории: **Settings → Pages**.
3. **Source:** `Deploy from a branch`.
4. **Branch:** `main` + папка `/ (root)` → **Save**.
5. Через минуту сайт будет доступен:
   **https://sirgopadawan.github.io/solar-system-deepseek-creator/**

### Альтернатива: three.js с CDN (без `vendor/`)

Если не хочется хранить three в репозитории, замените `importmap` в `index.html` на:

```html
<script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@0.186.1/build/three.module.js",
      "three/addons/": "https://unpkg.com/three@0.186.1/examples/jsm/"
    }
  }
</script>
```

Тогда `vendor/` не нужен, но сайт будет зависеть от интернета и CDN.

> Почему не «открыть index.html двойным кликом»: ES-модули не грузятся с `file://`.
> На GitHub Pages это http, поэтому всё работает; локально используйте `npm start`.
