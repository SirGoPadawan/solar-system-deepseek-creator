# 🌌 Three.js — Солнечная система

Интерактивная 3D-сцена Солнечной системы на [Three.js](https://threejs.org/):
процедурные текстуры планет, фоновая туманность, бесконечное звёздное небо и полёт
системы сквозь космос с винтовыми (спиральными) следами планет.

## ✨ Что есть в сцене

- Солнце + **8 планет**, включая Уран и Нептун.
- **Орбитальная механика по Кеплеру**: угловая скорость `n = SPEED_FACTOR / sqrt(R³)`,
  **эллиптические орбиты** (эксцентриситет у каждой планеты), **наклон плоскостей** 0–7°
  и осевое вращение; у **Венеры — ретроградное** вращение.
- **Солнце**: шейдерная фотосфера с лимб-даркенингом и «кипением» плазмы, пятна (умбра+полутень),
  корона и пульсирующие ореолы.
- **Процедурные текстуры** (шум fBm) и наклоны осей планет (`axialTilt`).
- **Атмосферное свечение** (fresnel) у Земли, Венеры, Марса и газовых гигантов.
- **Кольца Сатурна** из нескольких полос со щелями.
- **Спутники планет**: Луна, Фобос/Деймос, галилеевы спутники, Титан, Тритон и др.
- **Искусственные аппараты**: МКС, Hubble, Juno, Cassini, Voyager 2, Akatsuki — с мигающими маяками.
- **Пояс астероидов** (~1000 камней между Марсом и Юпитером) и **пояс Койпера** (за Нептуном):
  `THREE.InstancedMesh`, неровные камни на эллиптических орбитах.
- **Кометы** с газовыми хвостами, направленными от Солнца.
- **Tesla Roadster со Starman** (запуск Илона Маска) на вытянутой гелиоцентрической орбите.
- **Сетка эклиптики** — полупрозрачная координатная сетка в плоскости Солнца: по ней читается наклон орбит.
- **Фоновая спиральная галактика** — процедурные **80 000** звёзд-точек (`THREE.Points`, один draw call)
  в рукава, с интерполяцией цвета от тёплого ядра к сине-фиолетовым концам и медленным вращением.
  Кнопкой **🎲 Другая** генерируется новая галактика (рукавов 2–7, своя закрутка и палитра),
  кнопкой **🌀 Вид** камера отлетает и показывает её целиком, **🪐 Система** — возвращает назад.
- Фоновая туманность (галактическая полоса + волокна), стримящееся звёздное небо, **винтовые следы**
  и **объёмный туман** `FogExp2` + лёгкое свечение фона (космос не абсолютно чёрный).
- **Карточка планеты** — клик по планете открывает над ней карточку с описанием, фактами
  и ползунками; она едет за планетой и крепится кнопкой 📌.
- **Подсказка при наведении** — рядом с планетой всплывает футуристичная плашка с массой,
  температурой и составом атмосферы.
- **Панель управления слева вверху**: скорость системы, тумблеры движения/объектов,
  показ/скрытие планет. Виньетка для «космической» темноты.

## 🚀 Быстрый запуск (одной командой)

```bash
npm start
```

Затем открой в браузере:

**http://localhost:8000**

Остановить сервер — `Ctrl+C`.

> Ничего доустанавливать не нужно: `npm start` запускает встроенный статический
> сервер (`server.js`) без внешних зависимостей.

### Проверка проекта

```bash
npm run check
```

Проверяет синтаксис, связи импортов между модулями `src/` и то, что всё
используемое API three реально есть в вендорном бандле (после бага с
`THREE.Color().mix()`, которого в three r186 нет и который ронял всю сцену).

### Другой порт

```bash
PORT=3000 npm start
```

### Почему не открыть `index.html` напрямую?

Проект использует ES-модули (`import` + `importmap`). Браузеры не грузят модули по
протоколу `file://`, поэтому нужен http-сервер — `npm start` его и поднимает.

## 🎮 Управление

- **ЛКМ + перетаскивание** — вращение камеры вокруг системы.
- **Колесо мыши** — приближение/отдаление.
- **ПКМ + перетаскивание** — сдвиг.
- **Наведение на планету** — всплывает плашка с массой, температурой и составом атмосферы.
- **Клик по планете** — над ней открывается **карточка**: описание, факты и ползунки
  («Скорость орбиты» — множитель к кеплеровской, «Вращение вокруг оси», «Размер», «Сбросить планету»).
  Кнопка **📌** пришпиливает карточку на месте, **×** закрывает.
- **Панель слева вверху**:
  - **Скорость системы** — `−` / `⏸` / `+` / `×N` / `⟲`;
  - **Движение** — тумблеры «Движение системы», «Вращение вокруг оси», «Винтовые следы», «Звёзды»;
  - **Объекты** — «Орбиты», «Сетка эклиптики», «Пояса астероидов», «Кометы», «Tesla / Starman»,
    «Туманность», «Космическая пыль»;
  - **Галактика** — тумблер «Показывать» и кнопки **🎲 Другая** (сгенерировать новую галактику),
    **🌀 Вид** (отлететь и посмотреть её целиком), **🪐 Система** (вернуться к Солнечной системе);
    под тумблером — строка с текущими параметрами (рукавов, закрутка, звёзд);
  - **Планеты** — чекбокс на каждую (показать/скрыть), клик по имени открывает её карточку;
  - кнопка `–` сворачивает панель.

Камера-наблюдатель статична: ощущение полёта создаётся движущимся звёздным небом и следами планет.
Исключение — кнопка **🌀 Вид**: она плавно отлетает от системы на ~1250 единиц, чтобы галактику было
видно целиком (снаружи сферический скайбокс прячется).
Тумблеры независимы — можно, например, остановить вращение, но оставить движение по орбитам.

## ⚙️ Что можно настроить

Все ключевые параметры — в `src/config.js`:

```js
export const PLANETS = [ ... ]       // состав системы: радиус, орбита, эллипс, наклон
export const SPEED_FACTOR = 0.21     // n = SPEED_FACTOR / sqrt(R³) — «гравитация» сцены
export const GALAXY = { ... }        // фоновая галактика: рукава, закрутка, цвета, вращение
export const COMETS = [ ... ]        // кометы: a, e, inc, speed, tail
export const TESLA  = { a, e, inc, speed, scale }
export const MOTION_SPEED = 5.5      // скорость «полёта» сквозь космос
export const SYSTEM_TILT_X = 0.15    // наклон плоскости системы
export const SYSTEM_TILT_Z = 0.6
export const TRAIL_TIME = 16         // длина спиральных следов
export const SPEED_STEPS = [0.1, 0.25, 0.5, 1, 2, 3, 5, 8] // шаги кнопок скорости
```

- Поля планеты: `distance` — радиус орбиты (большая полуось `R`), `speedScale` — множитель
  к кеплеровской скорости, `eccentricity` — вытянутость, `inclination`/`node` — наклон плоскости
  орбиты в градусах, `spinSpeed` (минус = ретроградное вращение, как у Венеры).
- `MOTION_DIR` **производный** — это нормаль плоскости орбит, поэтому спирали всегда
  перпендикулярны системе. Меняя `SYSTEM_TILT_*`, вы разворачиваете систему, и полёт
  подстраивается сам.
- Спутники и аппараты задаются прямо в планете: `moons: [{ name, radius, distance, orbitSpeed, color }]`
  и `artificial: [{ name, distance, orbitSpeed, inclination }]`.
- Пояса малых тел — в `src/config.js`: `ASTEROID_BELT` и `KUIPER_BELT`
  (`count`, `inner`/`outer`, `speedMin`/`speedMax`, `scaleMin`/`scaleMax`, `eccMin`/`eccMax`, `incMax`).
- Текстуры планет генерируются процедурно (шум fBm) в `src/textures.js` — палитры `SUN`, `LAND`,
  `JUPITER_BANDS` и т.п. тоже там.
- Свет, «тон» сцены и объёмный туман — в `src/main.js` (`toneMappingExposure`, `AmbientLight`,
  `rimLight`, `scene.fog`; сам `FogExp2` создаётся в `src/sky.js`).
- Тумблеры видимости/движения по умолчанию — объект `options` в `src/main.js`.
- Стили интерфейса — в `src/styles.css`.

Подробнее обо всех этапах — в `PROGRESS.md`.

## 🌐 Публикация на GitHub Pages

Проект — чистая статика, поэтому публикуется «как есть». Важно: `node_modules`
в `.gitignore` **не** коммитится, поэтому three.js закоммичен отдельно в `vendor/`,
а `index.html` через `importmap` ссылается именно на `vendor/`. Значит на GitHub Pages
всё заведётся без сборки.

### Первичная настройка (один раз)

1. Запушьте ветку `main`:
   ```bash
   git add .
   git commit -m "Add moons, belts and GitHub Pages setup"
   git push origin main
   ```
2. В репозитории: **Settings → Pages**.
3. **Source:** `Deploy from a branch`.
4. **Branch:** `main` + папка `/ (root)` → **Save**.
5. Через минуту сайт будет доступен:
   **https://sirgopadawan.github.io/solar-system-deepseek-creator/**

### Альтернатива: three.js с CDN (без `vendor/`)

Если не хочется хранить three в репозитории, замените `importmap` в `index.html` на:

```html
<script type="importmap">
  {
    "imports": {
      "three": "https://unpkg.com/three@0.186.1/build/three.module.js",
      "three/addons/": "https://unpkg.com/three@0.186.1/examples/jsm/"
    }
  }
</script>
```

Тогда `vendor/` не нужен, но сайт будет зависеть от интернета и CDN.

> Почему не «открыть index.html двойным кликом»: ES-модули не грузятся с `file://`.
> На GitHub Pages это http, поэтому всё работает; локально используйте `npm start`.

## 🛠 Известные особенности

- Генерация текстур планет синхронная и занимает ~1.5 c на старте (полный кадр появится сразу после).
- Полёт системы — визуальная иллюзия (система в центре, стримится фон) — чтобы камера
  оставалась статичной и сцена не улетала.
- Кнопки скорости масштабируют и орбиты, и стрим звёзд, и следы, чтобы картинка оставалась согласованной.
- Орбиты эллиптические, а угловая скорость считается по Кеплеру — поэтому дальние планеты
  (Нептун) делают оборот заметно дольше (при желании ускоряйте кнопкой `+`).
- Карточка и подсказка — обычный HTML поверх канваса, они привязаны к проекции планеты на экран.
- Галактика — процедурный фон: 80 000 точек считаются один раз при старте (десятки миллисекунд),
  дальше в кадре меняется только поворот, поэтому на FPS она почти не влияет.
